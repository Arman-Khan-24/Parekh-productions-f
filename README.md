# Offsiteio React + Tailwind clone

This is the React/Tailwind version of the localized Offsiteio homepage.

The original `D:\Claude Code\offsiteio-clone` folder is unchanged and remains the static HTML/CSS fallback. This folder copies its local assets and keeps the published visual CSS/markup as the fidelity source while React owns the mount point and runtime initialization. Tailwind is enabled with preflight disabled so its reset cannot change the original layout.

Run:

```powershell
npm install
npm run dev
```
